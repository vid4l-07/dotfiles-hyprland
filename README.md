## Instalación
1. Crear backups
```bash
cp -r $HOME/.config $HOME/config-back
```

2. Clonar el repositorio
```bash
git clone https://github.com/usuario/dotfiles.git
cd dotfiles
```

3. Copiar la configuracion
```bash
mv config/* wallpapers $HOME/.config
```
