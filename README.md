## Installation
1. Create backups
```bash
cp -r $HOME/.config $HOME/config-back
```

2. Clone the repository
```bash
git clone https://github.com/vid4l-07/dotfiles-hyprland.git
cd dotfiles
```

3. Copy the dotfiles
```bash
mv config/* wallpapers $HOME/.config
```
